I’m Gabe, a software developer. I made this browser arcade to explore how to organize AI agents into a development team. Claude agents write the code; I lead the team, design features, and set the visual direction.

I created a specific role for each agent: building features, reviewing code, or producing visual mockups. Each change is developed in a separate Git branch, put through automated tests and code review, then playtested by me before going live.

With each new game, I refine the workflow to ship features quickly, minimize costs, and maintain quality through structure and hands-on review.
