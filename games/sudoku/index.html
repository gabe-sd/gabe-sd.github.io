SUDOKU

Select a cell, then type a digit

Rules

Fill every row, column, and 3x3 box with 1-9, no repeats. A conflicting digit turns red right away.

Controls

  • Click a cell, then type a digit or use the number pad
  • Backspace, Delete, or ⌫ — clear a cell
